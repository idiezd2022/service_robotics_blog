PROJECT 01

Localized Vacuum Cleaner

Autonomous service robotics project

01 — Introduction

This project focuses on the development of a localized autonomous vacuum cleaner for service robotics applications.

The objective is to create a robot capable of navigating autonomously through an environment while determining its own position.

02 — Project Overview

The system combines localization, navigation, perception and motion control to allow the robot to operate autonomously.
